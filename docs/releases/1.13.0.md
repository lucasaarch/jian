### Secrets

* **One Secret, every field:** A Secret now keeps everything a service needs together, such as a user, a password and a token, each with its own variable, plus the sites it belongs to. You find them in the agent's settings under **Secrets**, where you can see who made each one and which other agents may use it. A sensitive value never shows on screen: you type it once, and to change it you type a new one.
* **Commands get the whole Secret:** When a command uses any one variable of a Secret, `run_command` lends it every field of that Secret.
* **Agents manage their own:** An agent can list, save, delete and share Secrets. It saves a key you give it, or one it just created on a site, and shares it with another agent when that agent needs it for a job you gave it.
* **Values stay out of the history:** A value sent to `save_secret` is masked in what the run stores, even when the call was cut off, malformed, or had its fields written as a string of JSON.
* **No pointless approvals:** In a conversation that asks first, a command that wants a variable the agent may not use is refused right away, instead of after you approved it.
* **Contacts get no Secret tools:** A person using an app through the API Server is no longer treated as you, so their conversation has no Secret tools. Your own API conversations keep them.
* What you typed in the Secret dialog is forgotten once it closes.

### Artifacts

* **Password on a public link:** A public Artifact can have a password, which you set, change or remove from the panel. Whoever opens the link sees a form first, and the right password lets them in for 24 hours. Only a hash of the password is stored.
* The Download menu on the public page now opens and closes like the panel's other menus.

### Models and tools

* **Deferred tools work with every MCP server:** When an MCP tool's input was a `oneOf`, `anyOf` or `allOf` at the top level, Anthropic refused it, and the run went on with no deferred tools at all. Such a schema is now merged into a single object.
* **Quieter logs:** Images and PDFs in tool results use the AI SDK's current `file` format, so the hundreds of deprecation warnings are gone from the gateway's log. The strict mode warnings about `env` and Fastify's `FSTDEP022` warning at start are gone too.

### Upgrading

* The desktop app updates itself to this release. Remote workers update themselves as well.
* **Servers:** Recreate the gateway and web containers with the 1.13.0 images, or follow the `latest` tags.
* **Migrations:** This release runs two. `0117_artifact-password` adds the password to Artifacts. `0118_secrets` creates the Secrets tables, copies every existing command secret into them along with which agents may use it, and then drops the old `command_secrets` and `command_secret_agents` tables. Nothing is lost, but back up the database first if you want a way back to 1.12.
