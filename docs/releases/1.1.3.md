### Conversations

* **Sent at once:** a message appears in the conversation the moment it is sent, as a messenger shows it, and goes to the gateway behind it. One that could not be sent turns red with why, to send again — as the same message, never twice — or let go.
* **Listener wake-ups stay in the background:** when a GitHub listener fires, or a subagent finishes, the agent reads the gateway's note and acts on it; the conversation no longer shows that note as if the owner had written it.
* **How full the context is:** a ring beside the protection fills as the conversation's context does, amber past 60% and red where the gateway compacts on its own. Opened, it says the last call's input against the room the model leaves, the tokens the conversation's turns have taken (cached input apart), how many turns, and the last compaction: when, and from how many tokens to how many.
* **Compact now, or `/compact`:** the ring's button, or `/compact` written alone, compacts the conversation's context at once, the same way the gateway does when it fills; the agent only says what it came to. A WhatsApp or Telegram conversation keeps compacting on its own, without the button.
* **A long turn under memory pressure carries on:** a gateway that stalled a minute — a test suite filling the machine's memory — used to declare its own running turn dead ("Worker lease expired"). A turn the gateway is still running is now renewed, not interrupted; a renewal that fails once is tried again instead of stopping the turn; and on Linux the agent's commands are the first the kernel ends when memory runs out, never the gateway. A turn lost to a real restart now says so in plain words.
* **Errors can be copied:** what went wrong — an interrupted turn's card, a message not sent, an alert or a toast — selects as text again, to search, report or paste to the agent.
* **Work between answers sits closer:** a stretch of work after something the agent said is as near to what it says next as the first stretch is to its answer.

### The desktop app

* **Notifications that arrive:** an agent that finishes in a chat you are not looking at — the window hidden, minimized, behind another app, or on another chat, agent or gateway — sends a system notification, and opening it opens that chat. So does a question or an approval waiting on you, ahead of anything else in that chat, and a new message in a WhatsApp, Telegram or agent conversation. One per chat at a time, the newer replacing the older; Settings › General turns them off. Until now none was ever shown: a chat open behind another app counted as read, and only the open gateway's own chats were watched.
* **Windows starts its own gateway:** 1.1.2's stopped on the first release note it read, which the Windows build had checked out with CRLF line endings, and the app showed Loading agents for ever. Notes are read with either ending, a note that cannot be read is left out rather than stopping the gateway, and the repository checks every text file out with LF.
* **A gateway that cannot start says why:** the app's own gateway writes everything to local-gateway.log in the app's log folder, and when it ends before it is ready the window shows its last words, with Try again now and Show the log, instead of loading for ever. Every desktop build now starts the gateway it packaged, the way the app does, and fails when it does not answer.
* **Where a closed window went:** on Windows and Linux, closing the window leaves Jian running in the notification area; the first time, a notification says so and how to quit it.
* **Linux:** the AppImage and the `.deb`, for x64 and ARM. 1.1.2's Linux builds stopped before packaging, as a `.deb` names the project's home page and the app named none; it is usejian.app.
* **Mac builds that ride out Apple's servers:** stapling asks Apple for the ticket notarization has just issued, and the connection sometimes drops. 1.1.2's Apple silicon build failed so and was built again by hand; packaging, and the check of the ticket after it, now try again by themselves, twice at most, and only for that.

### English throughout

* **The last Portuguese words are gone:** a shell result's note on what was left out, an error reading the model catalog, the name of a profile that was removed, and `make setup`'s messages are now in English, as is every example and test.

### API

* **`GET /v1/profiles/{profileId}/sessions/{sessionId}/context`:** the last call's input, the room and the window, where compaction starts, the conversation's token totals and its last compaction.

### Upgrading

* From 1.1.0 or 1.1.2, recreate the gateway and web containers with the 1.1.3 images, or follow the `latest` tags. No migration runs, and nothing changes for a machine's worker.
* The desktop app updates itself to this release.
