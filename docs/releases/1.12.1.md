### Plugins

* **AWS without the deprecation notice:** AWS has stopped developing the AWS API MCP server, so every AWS tool's description started with a deprecation notice. Each AWS account now goes through AWS MCP Server, which AWS hosts, with the same access keys. AWS runs that server in eight regions. Jian uses your account's region when it is one of them, otherwise one on the same continent, otherwise N. Virginia. Your calls still go to the region you entered for the account.
* **Reactive Resume connects:** Clicking Connect on Reactive Resume failed with `servers.18.name: must match pattern`. It connects now.

### Upgrading

* The desktop app updates itself to this release. Remote workers update themselves as well.
* **Servers:** Recreate the gateway and web containers with the 1.12.1 images, or follow the `latest` tags. Migration 0116 runs when the gateway starts.
* **AWS accounts you already have:** Migration 0116 moves them to the N. Virginia server, because their region is in the vault and the migration can't read it. Calls still go to the account's region, and the keys stay as they are. Tools you had turned off for an AWS account are turned back on, because the new server's tools have other names. To pick a closer server, remove the account and add it again.
