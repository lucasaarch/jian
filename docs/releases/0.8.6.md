### MCP

* **Static OAuth clients:** when an authorization server has no `registration_endpoint` (RFC 7591), Jian no longer stops at "does not support dynamic client registration." Enter a pre-registered **OAuth client id** (and **client secret** when the app has one) on the MCP server, then use **Test the connection** to sign in. GitHub Copilot MCP at `https://api.githubcopilot.com/mcp/` needs a GitHub OAuth App or GitHub App whose callback is this gateway MCP OAuth callback (`JIAN_PUBLIC_URL` required). Servers that still support dynamic registration leave those fields blank.
* **Create MCP Server:** the **Start from** preset picker is removed. Configure the transport, URL or command, and auth fields directly.

### Upgrading

No database migrations. Recreate the gateway container with the 0.8.6 image. After upgrading, edit the GitHub HTTP+OAuth MCP server (if present), add the OAuth App client id and secret, then **Check** / sign in again.
