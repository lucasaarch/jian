### MCP

* **GitHub Copilot MCP without panel client secrets:** for `https://api.githubcopilot.com/mcp/` (and the same auth server shape), configure one GitHub OAuth App on the gateway with `JIAN_GITHUB_OAUTH_CLIENT_ID` and `JIAN_GITHUB_OAUTH_CLIENT_SECRET`. Register a single callback: `{JIAN_PUBLIC_URL}/v1/mcp/oauth/callback`. In the panel, add the HTTP URL, choose **Sign in to the server (OAuth)**, save, **Test the connection**, and sign in — no client id or secret on the MCP form. Per-server client id/secret remain under **Advanced OAuth client** for other non-DCR auth servers only.
* **One MCP OAuth callback:** every MCP OAuth redirect returns to `/v1/mcp/oauth/callback`. Profile and server travel in OAuth `state`, so one OAuth App covers every profile and server name.
* **Create MCP Server:** the **Start from** preset picker is removed. Configure the transport, URL or command, and auth fields directly.

### Upgrading

No database migrations. Recreate the gateway container with the 0.8.6 image. Set the two GitHub OAuth env vars (and `JIAN_PUBLIC_URL` if missing), point the OAuth App callback at `/v1/mcp/oauth/callback`, remove any client id/secret previously saved on the MCP server if you used the interim per-server fields, then **Check** / sign in again.
